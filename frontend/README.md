# Portfolio — Next.js

Application Next.js (App Router) multilingue (`fr` / `en`).

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) (redirection vers `/fr` ou `/en` selon la langue).

## Pages

- `/[locale]` — accueil  
- `/[locale]/contact` — lien mail vers pierreglerant@gmail.com  

## Scripts

| Commande        | Description   |
|-----------------|---------------|
| `npm run dev`   | Mode dev      |
| `npm run build` | Build prod    |
| `npm run start` | Serveur prod  |
| `npm run lint`  | ESLint        |
